# Mock — Python mashqlari

Ushbu repository Python tilida bajarilgan bir nechta kichik mashqlarni o'z ichiga oladi. Har bir vazifa `main.py` faylida alohida bo'lim sifatida yozilgan.

## Vazifalar ro'yxati

### 1-vazifa — Takrorlanmas ro'yxatlarni ajratib olish
Berilgan ro'yxatlar ichidan faqat bir marta uchraydigan (noyob) elementlarni ajratib olish.

### 2-vazifa — Matritsalarni qo'shish
Ikkita matritsa (ro'yxatlar ro'yxati) elementlarini mos indekslar bo'yicha qo'shish.

### 3-vazifa — O'tish balini hisoblash
Talabalarning baholari ro'yxatidan o'tish balidan yuqori bo'lgan talabalar sonini hisoblash.

### 4-vazifa — So'zlarni filtrlash
Berilgan so'zlar ro'yxatidan "gram" bilan tugaydigan so'zlarni ajratib olish (katta-kichik harflarga bog'liq bo'lmagan holda).

### 5-vazifa — Kontaktlar bo'yicha qidiruv
Kontaktlar lug'atidan ism bo'yicha telefon raqamini topish (katta-kichik harflarga sezgir bo'lmagan qidiruv).

## Ishlatish

Har bir vazifaning kodi izoh (comment) sifatida yozilgan. Ishlatish uchun kerakli bo'limni izohdan chiqaring (comment belgisini olib tashlang) va faylni ishga tushiring:

```bash
python main.py
```
